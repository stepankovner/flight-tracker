# FlightTracker

Реализуй проект строго по SPEC.md, этап за этапом. Перед реализацией каждого внешнего API сверься с актуальной документацией и сообщи о расхождениях.

Принятые решения и отклонения от ТЗ — в `docs/DECISIONS.md`; обновляй его при каждом новом решении.

## Правила кода
- `src/core/**` — чистые функции без Workers API, I/O и глобального времени (время передаётся параметром).
- Все SQL — только в `src/db/repo.ts`. Биндинг D1 используется через интерфейс `SqlDatabase` (`src/db/sql.ts`), чтобы тот же код работал на `node:sqlite` (тесты, Docker).
- Импорты с расширением `.ts` (нужно для запуска в Node без сборки).
- Бюджет subrequests на вызов Worker — см. `src/config.ts` (`BUDGET`), D1-вызовы тоже считаются.
- Проверка: `npm run check` (tsc + vitest).
